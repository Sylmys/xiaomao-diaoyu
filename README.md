# 小猫钓鱼 V2.0（支持2—4人）

轻量级、电脑优先并兼容手机浏览器的好友联机扑克小游戏。

## 游戏规则
- 使用一副52张标准扑克牌，不含大小王。
- 房主创建房间时选择2、3或4人；朋友使用房间号加入。
- 2人：每人26张；3人：每人17或18张，额外一张随机分配；4人：每人13张。
- 玩家按A→B→C→D顺序轮流翻自己牌堆顶的一张牌，手牌为0的玩家自动跳过。
- 新翻出的牌与桌面上最近一张相同点数的牌匹配（花色不影响匹配）。
- 匹配成功时，当前玩家收走匹配牌至新牌之间的全部牌（含两端）。
- A、J、Q、K均按普通牌面匹配，J没有特殊效果。
- 所有玩家手牌都出完后结束，按收集牌数排名；最多者获胜，允许并列。

## 本地运行
需要 Node.js 18 或更高版本：`npm install` 然后 `npm start`。
打开 http://localhost:3000。异地好友联机需部署到支持 Node.js 和 WebSocket 的公网服务。

## 技术与限制
- 前端：原生 HTML/CSS/JavaScript；服务端：Node.js + Express + Socket.IO。
- 服务端负责洗牌、发牌、回合、匹配和胜负计算。
- 房间状态暂存在内存中，服务器重启后消失。
- 当前断线后不会自动恢复座位；游戏中断线会显示离线，该玩家的回合仍需其本人回来操作。
